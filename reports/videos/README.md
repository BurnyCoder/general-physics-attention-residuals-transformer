# Predetermined rollout videos

Truth is on the left and autoregressive prediction on the right. Each clip uses the first test trajectory and first fixed window for its dataset, seed 0, all 24 forecast steps, and one target-derived color scale across time. Convection displays buoyancy; the radiative layer displays density. Values are in training-standardized coordinates; magenta marks nonfinite predictions. See [the protocol](../../docs/protocol.md).
